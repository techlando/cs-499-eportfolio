For the software design and engineering category, I enhanced my Android Weight Tracking Application from CS 360 Mobile Architecture and Programming. For the enhancement, I improved the application by adding stronger login validation, a registration screen, forgot password functionality, and better field validation.

This enhancement demonstrates my ability to work with databases while also applying secure coding practices and thinking about how software should be maintained in a more professional environment.
